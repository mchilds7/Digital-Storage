The basics

💾

Storage vs. memory

Storage keeps data when the power is off. RAM is fast working memory that clears when you shut down.

📏

Capacity units

1 KB → MB → GB → TB, each about 1,000 times bigger than the last. A phone photo is a few MB; a movie is a few GB.

⚖️

What to compare

Capacity, speed, cost per GB, durability, portability and security. No single type wins in every category.
