02 Digital Storage Fundamentals

Introduction to digital storage

Digital storage keeps data as bits, which are 0s and 1s. Eight bits make a byte, and every file you save, from a note to a movie, is a long list of bytes.

💾

Storage vs. memory

Storage (secondary storage) keeps data when the power is off. RAM is fast working memory that clears when you shut down.

🧲

How bits are kept

Magnetic drives flip tiny magnetic regions. Flash drives trap electric charge in chips. Optical discs use a laser to read pits. Cloud storage keeps files on a provider's servers.

📏

Capacity units

1 KB, MB, GB and TB are each about 1,000 times bigger than the last. A phone photo is a few MB, a film is a few GB, and a laptop drive holds hundreds of GB to a few TB.

Five properties to judge storage

Every choice is a trade-off between these five.

📦

Capacity

How much data it holds, measured in GB or TB. Bigger drives cost more in total.

🚀

Speed

How fast data is read and written, in MB/s. It decides how quickly a computer starts and files copy.

🛡️

Durability

How well it survives drops, heat, wear and time. Moving parts and scratchable surfaces are weak points.

🎒

Portability

How easy it is to carry and plug into other devices. Small and removable is best.

💲

Cost

Compare price per GB, not only the sticker price. Cloud adds a monthly fee.

Backup, encryption and information security

🔁

Data backup

Any drive can fail, so keep copies. The 3-2-1 rule means 3 copies of your data, on 2 different types of storage, with 1 copy off-site (such as the cloud).

🔐

Encryption

Encryption scrambles data so only someone with the key can read it. Use it for data at rest (BitLocker, FileVault) and in transit (HTTPS). A lost drive stays private if it is encrypted.

🕵️

Information security

Security protects data from theft, loss and tampering. It covers who can access files, protection from malware, and safe disposal of old drives.

    Key takeaways

    • No storage type wins everywhere. Choose by capacity, speed, durability, portability and cost.
    • SSDs are faster and tougher. HDDs are cheapest per GB.
    • Keep 3 copies, on 2 media types, with 1 off-site.
    • Encrypt drives and protect accounts with strong passwords.

    Glossary

    Bit and byte

    A bit is a single 0 or 1. Eight bits make one byte.

    Non-volatile storage

    Storage that keeps data when the power is off, such as drives, discs and the cloud.

    HDD

    Hard disk drive. Stores data magnetically on spinning platters.

    SSD

    Solid-state drive. Stores data in flash memory chips with no moving parts.

    SATA

    An older connection standard for drives. SATA SSDs reach about 550 MB/s.

    NVMe

    A fast SSD interface that uses PCIe lanes, reaching several thousand MB/s.

    Flash memory

    Chips that keep data using trapped electric charge. Used in SSDs, USB drives and memory cards.

    Optical disc

    A CD, DVD or Blu-ray read by a laser. Blu-ray holds the most.

    Cloud storage

    Files kept on a provider's servers and reached over the internet.

    Data center

    A building full of servers and storage that powers cloud services.

    Backup

    An extra copy of your data. Follow the 3-2-1 rule: 3 copies, 2 media types, 1 off-site.

    Encryption

    Scrambling data so only someone with the key can read it.
